# Sparkle code review order

This checklist covers the production C++ code in `include/` and `src/`. The order is intentionally pedagogical rather than alphabetical: fundamental values and utilities come first, followed by reusable containers and patterns, platform/input primitives, graphics and rendering, the engine, UI, and finally application orchestration.

Each checkbox represents exactly one file. A class or component therefore appears on consecutive lines when its declaration and implementation are split across files.
