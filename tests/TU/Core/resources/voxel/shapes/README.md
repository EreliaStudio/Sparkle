# Voxel Shape test fixtures

Each JSON file describes exactly one `spk::Voxel::Shape`. The fixtures are derived from historical [Erelia v1 voxel assets](https://github.com/EreliaStudio/Erelia_v1/tree/archive/erelia-v1/resources/voxels), with the former multi-Shape `shapes.json` split into `cube.json` and `slab.json`.

| File | Source | Polygons |
| --- | --- | --- |
| `cube.json` | `shapes.json` → `cube` | 6 |
| `slab.json` | `shapes.json` → `slab` | 6 |
| `slope.json` | `shapes/slope.json` | 5 |
| `stair.json` | `shapes/stair.json` | 10 |

## Shape JSON format

The root contains `id` (fixture metadata), `slots` (an object mapping geometric slot keys to opacity values in `[0,1]`), and `polygons` (an array). Each polygon has a `slot` key and a `vertices` array. Each vertex may be an XYZ position array or an object with `position`, optional `uv`, and optional `normal`.

The `Shape::Builder` also accepts the legacy `{"id": ..., "data": {"slots": ..., "polygons": ...}}` nesting. Historical XYZ-only vertices use zero UV coordinates and geometric lighting normals. The polygon winding remains exactly as authored; no two-sided faces are synthesized.

Tests load the files through `spk::JSON::Value::loadFromFile` and `Shape::Builder::addFromJSON`. These fixtures are intentionally retained as test resources for later geometry, meshing, and graphical golden-image tests. No image baseline is generated by PR-01.
