# PR 08.4 — Renommage du Core Assembly

> **Historical PR document, superseded by the merged PR-08 API.** Its examples and namespaces reflect an intermediate implementation. The final classes are `spk::Model3D::Blueprint`, `ObjectHeadless` and `Object<TGraphics>`; see [the implemented architecture](IMPLEMENTED-01-08.md). Do not implement the old Assembly/Puppet names.

Cette PR est volontairement limitée aux noms des classes Core, sans implementation de rendu.

- L'ancien `spk::Assembly` devient `spk::Assembly::Blueprint` (définition immuable, partagée).
- L'ancien `spk::Assembly::Instance` devient `spk::Assembly::Puppet` (occurrence articulée mutable).
- `Assembly::Element` et `Assembly::Builder` deviennent `Assembly::Blueprint::Element` et `Assembly::Blueprint::Builder`.
- `Attachable` et `AttachmentNode` restent dans le namespace `spk::Assembly`; `Puppet::AttachmentNode` demeure un alias.
- Fichiers renommés : `include/structure/blueprint.hpp`, `include/structure/puppet.hpp`, `src/structure/blueprint.cpp`, `src/structure/blueprint_element.cpp`, `src/structure/puppet.cpp`, `src/structure/puppet_attachment_node.cpp`. Les fichiers de tests sont également renommés. CMake découvre automatiquement les fichiers via `GLOB_RECURSE`.

La prochaine PR, après validation de ce renommage, introduira `RenderablePuppet<TGraphics>` : héritage de `Puppet`, cache graphique indexé par `Puppet::ElementNode*`, synchronisé par parcours/génération lors de la capture. Pas de seconde hiérarchie ni de notifications de structure.

La PR ne modifie pas les comportements de pose, d'attachement et de déplacement des classes Core. Les tests existants ont été adaptés aux nouveaux noms.
