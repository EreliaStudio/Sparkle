# Getting started

1. Read the [library overview](overview.md) to choose Core or Graphics.
2. Follow [installation and build](installation.md).
3. Try the [first Core application](first-core-application.md).
4. Continue with [Engine architecture](../architecture/engine.md) or the [network message guide](../guides/send-network-messages.md).

For graphical applications, see [graphics and rendering architecture](../architecture/rendering.md) and [UI architecture](../architecture/ui.md). A complete graphical application tutorial is a future documentation addition: the current pages avoid presenting an untested runnable example.
